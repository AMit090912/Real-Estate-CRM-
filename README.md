# 🏠 Real Estate CRM Module

A web-based CRM system designed to manage real estate operations such as property listings, client management, and inquiries.

---

## 🚀 Live Demo
👉 https://amit6576.pythonanywhere.com/

---

## 📌 Features
- Add, update, and delete property listings
- Manage client details
- Track inquiries and interactions
- Admin dashboard for easy management
- User-friendly interface

---

## 🛠️ Tech Stack
- Backend: Django
- Frontend: HTML, CSS
- Database: SQLite
- Deployment: PythonAnywhere

---
